# Manage — platform employee guide

Sign in at Manage with a **superadmin** account.

## Live today

| Screen | What you do |
|--------|-------------|
| **Dashboard** | Society count, quick links, roadmap |
| **Societies** | Create a society; open detail |
| **Society → Structure** | Towers (buildings) → wings → rename/delete |
| **Society → Flats** | Add flats or CSV import (tower selected in UI) |
| **Society → Parkings** | Puzzle / open lots; CSV |
| **Society → Team** | Add chairperson / secretary / treasurer (phone for OTP) |
| **Society → Controls** | Suspend, SLA, feature flags for this society |
| **Users** | Search platform users; open memberships |
| **Audit log** | Platform activity timeline |
| **Account** | Password / PIN |

## Commercial (platform) — live

| Screen | What you do |
|--------|-------------|
| **Feature flags** | Turn Client App modules on/off per society |
| **Society settings** | SLA defaults, suspend society |
| **Subscriptions** | Assign Starter / Growth / Enterprise |
| **Discounts** | Pilot % or flat off platform fees |
| **Generate bills** | Platform subscription invoices |
| **Payments** | Mark platform fees paid (offline) |
| **Announcements** | Broadcast to society staff (in-app) |
| **Integrations** | Read-only health (OTP / email / storage configured?) |
| **Support** | Inbox for society staff tickets |

Day-to-day residents, complaints, bills for **maintenance** stay in the **Client App**.
