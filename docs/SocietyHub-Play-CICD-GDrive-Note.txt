============================================================
WHAT THIS IS
============================================================
SocietyHub Android app (package com.societyhub.societyhub_mobile) is built by
GitHub Actions workflow "Mobile CI" (.github/workflows/mobile.yml).

CI can:
  1) flutter analyze + test
  2) Sign a release AAB (upload keystore in GitHub secrets)
  3) Upload that AAB and roll out the Play INTERNAL track (testers can install)

CI never publishes Production. Production stays a Play Console click.
New personal Play accounts also need Closed testing: 12 testers for 14 days
before Google unlocks "Apply for production".

============================================================
HOW TO RUN A STORE BUILD
============================================================
GitHub → Actions → Mobile CI → Run workflow
  Use workflow from: staging (or main after promote)
  Build IPA:         false
  Upload to Play:    true

Result:
  Artifact societyhub-android-aab
  Play Console → Internal testing → release is live for opted-in testers
  Closed testing testers and Production stay Console clicks.

Local AAB (same signing), if CI is down:
  apps/mobile/build/app/outputs/bundle/release/app-release.aab

============================================================
IF SOMETHING BREAKS
============================================================
Play upload 403: invite play-upload@… in Play Console and wait.
Play upload 401: JSON secret missing or wrong environment.
AAB signing fail: ANDROID_KEYSTORE_* secrets on that environment.
Google Sign-In fail on Play build: add Play App Signing SHA-1 to
  societyhub-android (Play → App integrity → App signing key certificate).
